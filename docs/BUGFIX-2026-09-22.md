# Hata düzeltme notları

Bu sürümde yayın ve PWA tarafındaki somut sorunlar giderildi:

- Manifest içindeki boş `icons` dizisi kaldırıldı; uygulama ikonu eklendi.
- Manifest için `scope`, `start_url`, Türkçe locale ve açıklama tamamlandı.
- Service worker cache sürümü `v2` yapıldı; eski bozuk cache otomatik temizleniyor.
- Service worker artık uygulama kabuğunu, ikonu ve manifesti cache'liyor.
- Ağ yokken cache'den uygulamayı açıyor; ağ varken güncel dosyayı alıp cache'i güncelliyor.

## Yapay zekâ / hızlı giriş hakkında

Mevcut GitHub Pages sürümündeki hızlı giriş, harici bir yapay zekâ servisi değildir; tarayıcıda çalışan güvenli bir kural tabanlı ayrıştırıcıdır. Bu nedenle yalnızca tanımlı kalıpları anlayabilir. API anahtarını frontend'e ekleyerek sahte bir “AI” bağlantısı kurmak güvenli değildir.

Üretim AI entegrasyonu için sonraki doğru adım, server-side bir proxy veya Supabase Edge Function kullanmak, girdiyi doğrulamak ve kullanıcı onayı olmadan finansal kayıt oluşturmamaktır. Bu işlem tamamlanana kadar uygulama hızlı girişte belirsiz metinleri kaydetmek yerine hata göstermelidir.

## Cache temizleme

Güncelleme görünmezse siteyi bir kez tamamen kapatıp yeniden açın. Android Chrome'da site ayarlarından önbelleği temizleyin; ardından uygulamayı tekrar yükleyin.
